# Nairobi directory reference information

Accessed **9 October 2026**. This records public reference evidence, not collection acceptance or stakeholder validation.

- Nairobi City County's [Integrated Development Plan 2023–2027, hosted by the County Assembly](https://www.nairobiassembly.go.ke/ncca/wp-content/uploads/2023/04/NAIROBI-CITY-COUNTY-INTEGRATED-DEVELOPMENT-PLAN-FOR-2023-2027.pdf), printed pages 6–8 / PDF pages 16–18, identifies Westlands and Kasarani and lists Kilimani as a ward. These names are used as geographical examples in Administrator and Consumer guidance. No facility coordinates/address, operating hours, licence, capability or collection acceptance is inferred. The current ward-office web page timed out; it is not relied on.
- Kenya Business Registration Service [Companies Registry](https://brs.go.ke/companies-registry/) and [official-search instructions](https://brs.go.ke/wp-content/uploads/2023/07/How-to-Apply-OS.pdf) describe official searches using an entity's name/registration number. The optional `ke_brs` namespace is a project identity choice. An Administrator must independently check the actual number and retain private evidence; the application does not contact the registry or establish e-waste licensing. No actual organization's number or public contact is introduced.
- OpenStreetMap Foundation [Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/) was rechecked for the shared pickup/site component: correct HTTPS tile URL, visible attribution, browser User-Agent and site-origin Referer, normal browser caching, no prefetch/offline/bulk downloads or headless requests against live tiles. Optional loading and manual fallback remain. The service is best-effort with no SLA; deployment usage/provider suitability must be reviewed. Browser automation uses local synthetic tiles, not public tile traffic.

## Synthetic demonstration content

`synthetic-study-operator-1`, the three `synthetic-study-*` places, their capabilities/hours and `SYNTHETIC-STUDY-1.0` geometry are fictional. Fresh setup labels them Nairobi synthetic study records. The coordinates/polygon are retained hand-defined test geometry, not surveyed facility entrances or the official county boundary. Demo setup/refresh does not alter user-created rows or synthetic markers. The separately user-authorized duplicate test-name correction to **Nairobi Test Operator 02 (Synthetic)** is recorded in the [Phase 4 report](phase-4-report.md); it establishes no real operator or collection acceptance.

`Akinyi Otieno · demo-contact@example.test` is explicitly a fictional synthetic contact example in private form guidance. No account/person/contact is seeded from this example and no message is sent. No real organization, facility, address, private person, phone number or email contact is seeded by this increment.

`app:refresh-nairobi-demo-copy` defaults to preview. `--apply` changes only the exact old name of known untouched, unreferenced synthetic seed records (version 1, no private contact or management history). Operationally linked, edited, real, absent and already updated records are retained. Organization names with linked places are retained. Only the name changes; permanent codes/IDs, coordinates/hours/capabilities/statuses and synthetic markers remain. This command was not applied to development during implementation.
