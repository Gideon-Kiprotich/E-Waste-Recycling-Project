New work invalidates old passes; a fresh test always binds latest actual completed work and current inspection/inventory configuration. Observation/reassessment changes may require a fresh test against retained genuine work, without inventing repeated repairs. Work cannot be adopted from a different custody context.

Current accepted compatible facility control, active scoped Processor, latest inspection and explicit current **REFURBISH** decision are mandatory. Admin cannot impersonate staff/owner. Failed/incomplete ordinary work/tests requires a fresh inspection plus a fresh decision; merely deciding again on the old inspection is insufficient. Recorded configuration changes/uncertainty, test safety/configuration restrictions and prior hard holds stay blocked pending unavailable reviewed correction. Notes cannot approve replacements or reconstructed configurations.

Whole-device release calls the existing live `media_coverage` calculation: complete applicable inventory, every applicable medium's assurance, or explicitly justified technician-NO/N/A. Standalone HDD/SSD uses existing current satisfied assurance, permanent YES and no destruction concern. No new sanitization-status ledger exists. Qualifying basic ICT fans require separate encrypted evidence/justification bound to current technician NO findings. UNKNOWN, unsupported non-HDD/SSD media, incomplete/disputed inventory, staleness and destruction block release. Even satisfied destruction assurance does not establish reusability.

## Authorization, acknowledgment and custody

`reuse_authorizations` projects a human authorization and terminal action; a partial unique index allows only one pending authorization per parent. `reuse_manifest` freezes the exact parent plus every confirmed canonical medium and source owner/control versions. The authorization context also freezes current work/test/N/A, inspection/decision, inventory/placement, each medium's assurance/authorization and relevant facility/operator/staff and recipient account/session/membership versions. Any relevant monotonic version change prevents revival even when eligibility is restored. Stale authorizations need explicit withdrawal before replacement. No automatic expiry is introduced. A currently authorized facility Processor can safely withdraw after capability loss without bypassing release gates.

The authenticated existing Consumer owner must select **every** displayed item and explicitly attest actual complete receipt. Staff assertion, generic confirmation, private document or a subset cannot substitute. Live gates and the frozen context are rechecked under transaction locks at acknowledgment, and dependencies changed later in the same transaction are rejected by forced deferred checks. Incomplete/mismatched return appends an exception and closes authorization without transferring any item; further routine release stays blocked pending separately reviewed correction.

`reuse_return_items` records one terminal owner return per physical subject. Valid acknowledgment atomically appends a physical event and advances current custody/subject versions once for the parent and all manifest media, setting released state. Original identities, labels, owner, placements, origins, first receipts, facility handovers, inspection and assurance remain. Derived media extends its actual facility-identification provenance, not a fabricated first receipt. Historical chain and inspection validators accept only this reciprocal ledger-backed terminal extension; independent embedded-media movement remains blocked. A recorded release cannot be deleted, reversed to assessed or silently moved again. Later contradictory information needs reviewed correction, not history rewriting.

Release authorization alone changes no custody. This return is neither a new collection/first receipt nor disposal or ownership transfer. Future report cohorts must distinguish the authorized root return from physical manifest members; derived media never creates another collected-item count. Historical treatment after owner return is not presented as a guarantee about subsequent owner use.
