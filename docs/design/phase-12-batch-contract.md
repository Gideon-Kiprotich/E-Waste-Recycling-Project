# Phase 12 batch and detachment contract

Recorded before implementation on 18 October 2026. Authority: CR-BATCH-01, explicitly extending CR-MEDIA-01/CR-PARTS-01. D3 S12 supplies workspace composition; reuse existing Blade cards, feedback, fields, history, label and private-evidence patterns. No new Stitch export is claimed.

## Workflow and identities

Save draft → Record actual dismantling → Record output / Record measurement correction → Attest complete output accounting. Draft selections confer no reservation. A batch has one permanent subject/label and facility accountability, no invented individual owner. Inputs retain their owners and permanently join one batch. Commitment explicitly confirms actual work and every identified surviving drive. Physical media must already have coherent confirmed canonical identity, undestroyed state, same owner as the source and same facility control; retain custody unchanged. All historical placement rows remain, while an immutable batch detachment ends active embedding. No re-parenting or independent transfer follows.

Outputs have a single production record. Ordinary material/component/residue lots are aggregate output subjects. A surviving drive uses exactly its canonical item/subject/storage ID as an output facet; its measured output is already included in parent input mass, never another input. Source parent is optional for aggregate lots and allowed only when genuinely evidenced; absent source means aggregate batch lineage, not a guessed owner. No recovered individual fan/part registration is added. For this on-site-only increment, aggregate control is the immutable batch facility party; canonical items retain their actual custody rows. A later aggregate transfer needs its own acknowledged-custody contract, never a fabricated first receipt. Unexpected post-commit media blocks accounting and new treatment; no guessed provenance, identity, owner or correction is created.

## Measurements, accounting and corrections

All measurements use kg, numeric(12,3); application input rejects more than three decimal places/exponents rather than silently rounding. Net mode requires net > 0 and no gross/tare. Gross/tare mode requires gross > tare >= 0 and exact net = gross − tare. Missing draft/input measurement keeps a draft. Output production may be observed with unknown mass; this produces one pending lot, not zero measured stock. Later measurement/correction points to the current measurement record (or explicit absent predecessor), retains original facts, reason and evidence, and replaces the projection, never adds production.

Signed variance = measured input − sum of each currently measured produced output once. Tolerance = max(0.100 kg, input × 0.02) with exact numeric arithmetic. Partial measurements are pending; output-completeness attestation is a separate explicit assertion invalidated by subsequent output/measurement changes. Excess variance blocks reconciliation but never honest measurement recording. Recorded stock = latest measured production per lot; missing mass is unknown. No dispatchable quantity is promised: dispatch/reservation/deduction is unavailable in this increment. No automatic loss, balancing output, recovery yield, closure or downstream completion is generated. A future movement ledger must adopt the existing production record/subject, never seed duplicate stock. Treatment records alone do not consume or transform stock; subsequent physical output/loss/movement accounting is separately bounded.
